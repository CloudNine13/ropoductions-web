## Findings

### Aggregate Views & Architecture Delta

- **Finding 1.1: Design Tokens & Typography Shift (Chakra Petch & Studio Emerald)**
  - **Source:** `src/app/globals.css:17`, `src/lib/fonts.ts:1-12`, commit `0c85690`
  - **Description:** Story 1.1 and SPEC.md originally specified display typography in `Cinzel` serif and primary color in Crimson flame (`#E11D48`). In Story 1.2 (commit `0c85690`), the typography was transitioned to `Chakra Petch` (Google Fonts) and primary accent to Studio Emerald (`#22C55E`) to match pixel art game assets and cyberpunk/retro-tech aesthetics. A backward-compatibility alias `export const cinzel = chakraPetch;` was left in `src/lib/fonts.ts`.
  - **Disposition:** *Accept as-is / Spec Reconciliation*. Update planning artifacts in Epic 2+ to standardize on Studio Emerald (`#22C55E`) and Chakra Petch.
  - **Prevention:** Record design token evolution in design system notes when asset themes dictate aesthetic deviations.

- **Finding 1.2: Age Gate Cookie Duration Locked to 5 Days**
  - **Source:** `src/lib/cookies.ts:2`, commit `911e2bf`
  - **Description:** FR-2 originally drafted a 30-day cookie for `ropoductions_age_verified`. In commit `911e2bf`, `AGE_VERIFIED_COOKIE_MAX_AGE` was set to `5 * 24 * 60 * 60` (5 days = 432,000 seconds). The project owner explicitly confirmed and locked the 5-day retention period.
  - **Disposition:** *Accept as-is / Spec Reconciliation (Resolved)*. Lock `AGE_VERIFIED_COOKIE_MAX_AGE` at 5 days (`432000` seconds) across all specifications, PRD, and agent instructions. Do not revert to 30 days. *(Updated 2026-09-17 per owner decision: cookie lifetime changed from 5 days to 14 hours / 50400s).*
  - **Prevention:** Record owner-mandated deviations as explicit constraints in project rules.
- **Finding 1.3: Expanded Multilanguage Support (Polish Locale Added)**
  - **Source:** `src/locales/pl.json`, `src/lib/i18n.tsx:13,31`, PR #3
  - **Description:** FR-19 specified multilingual support with English default and examples (EN, JA, ES, RU, ZH). Story 1.4 expanded this by adding a complete Polish dictionary (`pl.json` 🇵🇱), supporting 6 locales with full UI key coverage.
  - **Disposition:** *Accept as-is (Positive Enhancement)*. Reconcile documentation to catalog Polish among supported languages.

- **Finding 1.4: Cookie Parsing Quoting Inconsistency in Middleware**
  - **Source:** `src/middleware.ts:6` vs `src/lib/cookies.ts:14` vs `src/app/(portal)/layout.tsx:12`
  - **Description:** In `src/lib/cookies.ts` and `src/app/(portal)/layout.tsx`, cookie values strip surrounding quotes using `.replace(/^"|"$/g, "")` before checking equality. In `src/middleware.ts`, line 6 directly compares `request.cookies.get("ropoductions_age_verified")?.value === "true"`. If a user-agent sets quoted cookies (`"true"`), the middleware check will fail.
  - **Disposition:** *Fix now (Remediation)*. Update `src/middleware.ts` to normalize quotes when reading cookies.
  - **Prevention:** Share cookie reading/normalization helpers between edge middleware and server components.

- **Finding 1.5: Static Bundle Size of Client-Side Locale Dictionaries**
  - **Source:** `src/lib/i18n.tsx:6-11,38-45`
  - **Description:** All 6 locale dictionaries are statically imported into client bundle `i18n.tsx`. At present, all 6 dictionaries total ~30KB (lightweight, zero network waterfalls for switching). However, as game lore and descriptions expand, bundling all locales into client JS could grow client payload.
  - **Disposition:** *Defer (Track for Epic 3/4)*. Current footprint is small (~30KB), but should be monitored if dictionaries exceed 100KB.

- **Finding 1.6: Duplicated Cookie Manipulation Logic**
  - **Source:** `src/lib/cookies.ts:11-19,29-31` and `src/lib/i18n.tsx:104-114,122-124`
  - **Description:** Both files implement independent `document.cookie.split(";")` parsing loops and cookie string formatting (`max-age`, `SameSite=Lax`, `Secure`).
  - **Disposition:** *Defer (Chore)*. Extract shared cookie parsing/serialization into a unified utility in a future hygiene cleanup.

- **Finding 1.7: Verification Gap — Absence of Automated Unit / Integration Tests**
  - **Source:** `package.json:5-11`, workspace directory
  - **Description:** The project has zero test files or test runner configured (`vitest` / `jest` / `playwright`). All verification across Stories 1.1–1.4 relied strictly on compilation (`opennextjs-cloudflare build`) and manual smoke testing.
  - **Disposition:** *Resolved*. Configured native Node test runner (`node --test --experimental-strip-types`) with loader hooks and tsx verification scripts, covering edge middleware, cookie normalization, i18n fallback merging, Cloudflare D1 schema, and OAuth authorization, verified in GitHub Actions CI (`portal-checks.yml`).
