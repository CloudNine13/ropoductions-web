- (decision) Patreon OAuth gating with 5 tiers: Ork Patron ($5), Ogre Pimp ($10), Elf Sybarite ($15), Horseman Aesthete ($25), Mind Fucker Avatar ($50)
- (decision) Graceful subscription checking on navigation/interaction, never mid-play kick; redirect to home with renewal flow
- (decision) v1 save system relies on browser storage + .rpgsave file import/export; cloud saves parked for v3-v5
- (insight) Top v1 technical priority: game patching mechanism must preserve player browser save data across game updates
- (insight) Target audience is 21+ adult gaming community; requires age gate and adult content compliance
- (direction) Aesthetic blends AAA game studio polish (Bungie, Riot, Annapurna) with adult indie portal feel (OppaiLab, Dark Tether)
- (preference) Target infrastructure: Next.js frontend with Cloudflare CDN, Workers/Pages, and edge capabilities
- (decision) Core value props: zero-installation instant browser play and reduced piracy friction via authenticated gating
- (decision) Game developers guarantee save backward-compatibility via MZ plugins; web shell manages origin storage stability and manual backup tools
- (decision) Asset protection strategy: asset encryption (MZ native or third-party) combined with session-authenticated edge delivery
- (decision) All 5 patron tiers ($5-$50) receive identical web game access in v1; tier-differentiated perks parked for future versions
- (decision) Entry experience includes a 21+ age verification confirmation modal
- (decision) Entire web portal and game canvas wrapper must support responsive mobile scaling
